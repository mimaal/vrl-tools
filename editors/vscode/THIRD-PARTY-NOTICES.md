# Third-party licences

VRL Tools is MIT. The diagnostics, hover, completion and the `run` command come
from the real VRL compiler, which means the extension ships
`wasm/vrl_check_wasm_bg.wasm`: the [`vrl`](https://github.com/vectordotdev/vrl)
crate and its dependency tree, compiled to WebAssembly and statically linked.
Those crates keep their own terms, and this file carries them.

Two of them are worth naming.

**The `vrl` crate is MPL-2.0.** It is consumed as an unmodified dependency —
nothing in this repository patches or vendors it — so the MPL covers the
crate's own files and not the extension's. The version is pinned exactly, and
its source is at <https://github.com/vectordotdev/vrl> under the matching tag;
the pin lives in `crates/vrl-check-core/Cargo.toml` and the exact version is on
the status bar while you edit. If you want the source of the MPL-covered parts
of the binary in this `.vsix`, that is where it is.

**Everything else** is permissive: MIT, Apache-2.0 and the handful of licences
listed below.

This file is generated by `npm run gen:notices`, which walks the dependency
graph of `vrl-check-wasm` for `wasm32-unknown-unknown` — the build that ships —
and fails on any licence not accepted in `about.toml`.
